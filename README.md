Квиз-прелендинг «Персональная крипто-стратегия»

Тестовое задание «Верстальщик». Одностраничный квиз из 4 шагов (пол → возраст → цель → лоадер) с финальным экраном и кнопкой перехода на оффер. Тематика: крипта.

Чистые HTML, CSS и JS, без сборщиков и библиотек.

Запуск

Откройте index.html в браузере или запустите через Live Server (VS Code). Установка не нужна.

Структура
index.html   разметка всех шагов
style.css    стили (БЭМ, без CSS-переменных)
script.js    логика квиза
fonts/       Plus Jakarta Sans (woff2)
Что реализовано
4 шага + финал, прогресс «N из 4» сверху (лоадер считается четвёртым шагом).
Автопереход после выбора ответа (пауза 250 мс), плавное появление шага (fade + небольшой сдвиг).
Кнопка «Назад» на каждом шаге, кроме первого.
Ответы и текущий шаг хранятся в localStorage (ключ quiz:v1). После обновления страницы квиз продолжается с того же шага. Чтобы сбросить, удалите ключ в DevTools → Application → Local Storage.
Лоадер: 0 → 100 % за 3 секунды (прогресс-бар, процент и «свечи графика»), затем переход на финал.
Кнопка на финале ведёт на {offer} (макрос подставляется на вашей стороне).
Мобильная адаптивность: вёрстка mobile-first, брейкпоинты 360px и 768px.
Анимации отключаются при prefers-reduced-motion.
